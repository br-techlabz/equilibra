# TASK-UI-4 — Gate Visual, Responsividade, Acessibilidade e Consistência

Foram concluídas:

- TASK-UI-1 — Design System e refatoração visual global
- TASK-UI-2 — Dashboard e componentes visuais financeiros
- TASK-UI-3 — Refatoração visual de Login e Cadastro

Esta é a última tarefa da:

# Sprint UI — Refatoração Visual do Equilibra

Esta TASK é um **GATE DE QUALIDADE**.

O objetivo NÃO é redesenhar novamente a aplicação.

O objetivo é:

1. revisar toda a nova interface;
2. encontrar inconsistências;
3. corrigir problemas reais;
4. validar responsividade;
5. validar acessibilidade;
6. validar Design System;
7. validar regressões funcionais;
8. eliminar CSS desnecessariamente duplicado;
9. validar visualmente a aplicação;
10. decidir se a nova fundação visual está pronta para a Sprint 2.

---

# 1. Regra principal

NÃO faça uma nova refatoração geral.

NÃO altere a identidade visual aprovada sem motivo concreto.

Faça mudanças somente quando encontrar:

- bug visual;
- inconsistência;
- problema responsivo;
- problema de acessibilidade;
- CSS duplicado relevante;
- componente divergente do Design System;
- regressão funcional;
- problema de usabilidade.

# 8. Sidebar mobile

Valide como drawer/overlay.

Deve:

- abrir corretamente;
- fechar corretamente;
- fechar após navegação quando apropriado;
- permitir teclado;
- possuir foco previsível;
- não causar scroll horizontal;
- não ficar parcialmente fora da viewport.

---

# 9. Overlay mobile

Quando sidebar estiver aberta:

- overlay deve ser perceptível;
- clique fora pode fechar quando coerente;
- interação não deve ficar confusa;
- z-index deve estar correto.

Não use z-index arbitrariamente crescente para resolver problemas.
