# TASK-UI-1 — Design System e refatoração visual global do Equilibra

O Equilibra já possui sua infraestrutura inicial, autenticação e frontend Angular funcionando.

Antes de iniciar a próxima Sprint funcional, faça uma refatoração visual completa da aplicação.

A imagem anexada fornecida ao Claude Code deverá ser utilizada como **principal referência visual e estrutural**.

IMPORTANTE:

A imagem é uma REFERÊNCIA DE DESIGN.

Não copie:

- nome "Perfect Admin"
- textos
- dados
- logotipo
- imagens de usuário
- conteúdo específico
- identidade da aplicação original

Reinterprete o design para criar uma identidade própria do:

**Equilibra — Gestão de Finanças Domésticas**

---

# 1. Objetivo

Transformar a interface atual em um dashboard financeiro moderno inspirado estruturalmente na imagem de referência.

A aplicação deverá possuir:

- sidebar escura
- topbar
- área principal clara
- breadcrumbs
- cards financeiros
- painéis
- gráficos
- tabelas/listas
- menus hierárquicos
- identidade visual consistente
- responsividade completa

A nova linguagem visual deverá ser utilizada como base para TODAS as telas futuras do Equilibra.

# 5. Sidebar

A sidebar será um dos principais elementos visuais.

Utilize:

- fundo azul-cinza muito escuro
- texto claro
- ícones discretos
- divisores sutis
- item ativo destacado
- hover perceptível
- largura aproximadamente entre 230px e 260px

Não copie literalmente as cores da imagem.

Crie tokens próprios.

---

# 6. Marca

No topo da sidebar apresente:

**Equilibra**

Opcionalmente:

`Finanças Domésticas`

Use uma identidade tipográfica simples e profissional.

# 11. Submenus

Transações deverá suportar expansão/recolhimento.

Utilize animação curta e discreta.

O submenu deve manter boa navegação por teclado.

Não implemente animações exageradas.

---

# 12. Topbar

Crie topbar horizontal inspirada na referência.

Características:

- fundo escuro
- altura aproximada de 56–64px
- botão para sidebar
- espaço flexível
- identificação do usuário
- menu do usuário
- logout

Evite encher a topbar com notificações fictícias.

Não crie:

- mensagens
- alertas
- notificações

sem funcionalidades reais.

---

# 13. Breadcrumbs

Abaixo da topbar, ou no início da área de conteúdo, apresente breadcrumbs discretos.

Exemplos:

Home / Dashboard

Home / Contas

Home / Transações / Despesas

Crie componente reutilizável somente se isso fizer sentido arquiteturalmente.

---

# 14. Área principal

Use:

- fundo cinza extremamente claro
- cards/painéis brancos
- espaçamento consistente
- sombras discretas
- bordas suaves

Evite fundo branco absoluto em toda a página.

O contraste entre canvas e cards deve organizar visualmente o conteúdo.

---

# 15. Content container

Defina largura e espaçamento consistentes.

Desktop:

padding aproximado de 24px.

Tablet:

16–20px.

Mobile:

12–16px.

Não deixe conteúdo encostado nas bordas.
