# TASK-5.2 — INTERFACE DO RELATÓRIO FINANCEIRO

Objetivo:

Implementar no Angular a interface completa do Relatório Financeiro,
consumindo exclusivamente o backend real entregue pela TASK-5.1.

A tela deve permitir ao usuário:

- selecionar período;
- selecionar uma, várias ou todas as contas;
- aplicar filtros;
- visualizar saldo inicial;
- visualizar receitas;
- visualizar despesas;
- visualizar resultado financeiro;
- visualizar transferências de forma semanticamente correta;
- visualizar variação do saldo;
- visualizar saldo final;
- visualizar detalhamento das movimentações, caso previsto pelo ADR/API;
- compreender claramente a diferença entre resultado financeiro e
  variação do saldo.

Esta TASK é prioritariamente FRONTEND.

NÃO recalcular regras financeiras no Angular.

NÃO implementar exportação ainda.
