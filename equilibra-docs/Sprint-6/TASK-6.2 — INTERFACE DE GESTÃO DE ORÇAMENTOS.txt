# TASK-6.2 — INTERFACE DE GESTÃO DE ORÇAMENTOS

PROJETO: EQUILIBRA
SPRINT: 6 — PLANEJAMENTO FINANCEIRO
STACK: Angular 19 + Spring Boot 4 + MySQL

CONTEXTO

Sprint 5 aprovada.
TASK-6.0 — Arquitetura do Planejamento Financeiro concluída.
TASK-6.1 — Backend de Orçamentos por Categoria concluído.

OBJETIVO

Implementar a interface Angular para gerenciamento de
orçamentos mensais por categoria.

O usuário deverá conseguir:

- consultar orçamentos por competência;
- criar orçamento;
- editar valor planejado;
- remover ou arquivar orçamento conforme ADR;
- visualizar categoria associada;
- identificar categorias inativas;
- compreender conflitos de orçamento duplicado;
- navegar entre competências mensais.

Consumir exclusivamente a API real da TASK-6.1.

NÃO implementar cálculos de realizado, consumo ou alertas.

Na listagem histórica:

a orçamento existente.

==================================================
16. DUPLICIDADE
==================================================

Se já existe orçamento para categoria e competência:

não permitir duplicidade.

Frontend pode prevenir seleção duplicada
para melhorar UX.

Backend permanece autoridade.

Se API retornar 409:

mostrar mensagem clara.

Exemplo:

"Já existe um orçamento para esta categoria neste mês."

Não exibir stack trace.

==================================================
17. VALOR PLANEJADO
==================================================

Validar:

duas casas decimais;
limites;
formato inválido.

Não usar float para cálculos financeiros.

Não arredondar silenciosamente entradas inválidas.

==================================================
18. EDIÇÃO

26. PROBLEM DETAILS
==================================================

403:

404:
orçamento/categoria indisponível.

409:
conflito de duplicidade.

500:
mensagem segura.
