# Interface de Contas de Ativo

Esta TASK deverá criar a primeira interface CRUD financeira completa do Equilibra utilizando exclusivamente a API de AssetAccount já implementada.

A implementação desta tarefa deverá também estabelecer um padrão visual e arquitetural reutilizável para os próximos cadastros do sistema, sem criar abstrações CRUD genéricas prematuras.

---

# 1. Escopo

Implementar no frontend:

- acesso a "Contas";
- listagem das Contas de Ativo;
- criação;
- edição;
- desativação;
- reativação;
- visualização de contas inativas;
- estados de loading;
- estados vazios;
- tratamento de erros;
- responsividade;
- acessibilidade;
- integração real com a API da TASK-2.2.

NÃO implementar:

- Categorias;
- Despesas;
- Receitas;
- Transferências;
- Contas de Despesa;
- saldo atual calculado;
- transações;
- relatórios;
- integração do Dashboard com dados reais.

# 41. Representação interna

O formulário deverá trabalhar de forma segura com decimal.

JavaScript usa Number IEEE-754.

O frontend apenas captura e envia o valor.

Não faça cálculos financeiros aqui.

---

# 42. Casas decimais

# 43. Separador decimal

A aplicação deverá tratar a entrada de maneira previsível.
