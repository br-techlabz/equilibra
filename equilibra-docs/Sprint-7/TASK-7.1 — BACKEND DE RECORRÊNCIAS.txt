# TASK-7.1 — BACKEND DE RECORRÊNCIAS

PROJETO: EQUILIBRA
SPRINT: 7 — PREVISIBILIDADE FINANCEIRA
STACK: Spring Boot 4 + MySQL
SEGURANÇA: Spring Security + JWT + CurrentUser
QUALIDADE: Flyway + OpenAPI + Testcontainers/MySQL

CONTEXTO

Sprints 0 a 6 aprovadas.

TASK-7.0 — Arquitetura e ADR da Sprint 7 concluídos.

OBJETIVO

Implementar o backend de gerenciamento de regras
de recorrência para despesas e receitas.

Permitir que o usuário configure obrigações
e entradas financeiras periódicas.

A implementação deve seguir estritamente o ADR
da TASK-7.0 e preservar o ledger existente.

IMPORTANTE

Não presumir que uma recorrência é uma
transação financeira efetivada.

Não criar movimentos financeiros apenas
por cadastrar uma recorrência.

Não implementar frontend nesta tarefa.
