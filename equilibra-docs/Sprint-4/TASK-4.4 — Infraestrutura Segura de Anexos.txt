# TASK-4.4 — Infraestrutura Segura de Anexos

Objetivo:

Construir a infraestrutura backend segura e reutilizável necessária para
Attachments de transações financeiras.

Esta TASK deve implementar a FUNDAÇÃO de:

- modelo de metadata de Attachment;
- persistência;
- migration;
- abstração de storage;
- implementação local de storage para MVP;
- configuração;
- validação de arquivos;
- limites;
- MIME/media type;
- assinatura/magic bytes;
- checksum;
- geração segura de storage keys;
- proteção contra path traversal;
- consistência entre MySQL e storage;
- autorização/ownership preparada;
- testes.

IMPORTANTE:

Nesta TASK ainda NÃO implementar a experiência completa de upload nas
telas Angular.

Também não transformar esta TASK em implementação completa da API de
Attachments se o ADR separou infraestrutura de endpoints funcionais.

A TASK-4.5 será responsável pelo ciclo funcional de Attachments nas
transações.
