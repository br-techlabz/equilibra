# 3. PRINCÍPIO FINANCEIRO

Attachment é metadata.

Portanto:

upload attachment
→ efeito financeiro = 0.

download attachment
→ efeito financeiro = 0.

delete attachment
→ efeito financeiro = 0.

Nenhuma operação desta TASK pode alterar:

- amount;
- occurredAt;
- transaction type;
- transaction status;
- account;
- sourceAccount;
- destinationAccount;
- AccountMovement;
- currentBalance;
- netWorth.
