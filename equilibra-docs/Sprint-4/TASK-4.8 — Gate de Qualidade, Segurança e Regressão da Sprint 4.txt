# 4. CLASSIFICAÇÃO DE SEVERIDADE

Use:

CRITICAL
HIGH
MEDIUM
LOW

CRITICAL:

- cross-user data access;
- arquivo privado acessível publicamente;
- corrupção financeira;
- ledger inconsistente;
- transferência aplicada duas vezes;
- path traversal explorável;
- upload executável perigoso;
- perda grave de dados.

HIGH:

- autorização incorreta;
- saldo incorreto;
- net worth incorreto;
- Dashboard financeiro incorreto;
- paginação que omite/duplica transações;
- attachment ownership quebrado;
- Tag ownership quebrado;
- storage inconsistente de forma recorrente.

MEDIUM:

- UX funcional quebrada;
- tratamento incorreto de erro;
- race condition limitada;
- problema de acessibilidade relevante;
- query excessiva.

LOW:

- inconsistência visual;
- documentação;
- naming;
- pequenos problemas não funcionais.
