# TASK-4.3 — Associação de Tags às Transações

Objetivo:

Implementar a associação de Tags às transações financeiras do Equilibra:

- Expense;
- Income;
- Transfer.

A associação deve existir na TRANSAÇÃO FINANCEIRA LÓGICA.

Tags são metadata.

Tags NÃO podem modificar o efeito financeiro da transação.

Esta TASK inclui:

- persistência da associação;
- migration;
- domínio;
- casos de uso;
- API;
- DTOs;
- integração nos formulários Angular;
- exibição básica das Tags nas transações;
- testes;
- regressões financeiras.

O filtro avançado do Histórico por Tag pode ser preparado nesta TASK,
mas a integração completa do Histórico pertence à TASK-4.7, salvo se o
ADR 4.0 determinou explicitamente que o filtro deve nascer junto com a
associação.

Attachments permanecem FORA desta TASK.

# 28. EXISTING HISTORICAL INACTIVE TAG

# 29. UPDATE TRANSACTION WITH HISTORICAL INACTIVE TAG

Este cenário deve ser tratado cuidadosamente.

Não é aceitável apagar Tag B acidentalmente.

# 30. DECISÃO

Se update de transação envia conjunto completo de tagIds:

a UI precisa preservar Tags históricas já associadas quando não estiver
editando a associação.

# 31. INACTIVE EXISTING TAG

possuía.
