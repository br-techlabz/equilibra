# TASK-4.6 — Interface de Anexos em Despesas, Receitas e Transferências

Objetivo:

Implementar no Angular a experiência completa de anexos para:

- Despesas;
- Receitas;
- Transferências.

Consumir exclusivamente a API real implementada na TASK-4.5.

A solução deve fornecer:

- seleção de arquivo;
- upload;
- progresso quando tecnicamente suportado;
- validação antecipada no frontend;
- listagem dos anexos;
- download autenticado;
- remoção;
- estados de loading/upload/download/delete;
- tratamento de erros;
- acessibilidade;
- responsividade.

Criar UMA infraestrutura visual reutilizável para os três tipos de
transação.

Attachment continua sendo metadata.

Nenhuma operação desta TASK pode alterar o efeito financeiro da
transação.
