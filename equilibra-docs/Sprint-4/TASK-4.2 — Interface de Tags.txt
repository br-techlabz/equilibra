# TASK-4.2 — Interface de Tags

Objetivo:

Implementar no Angular a interface completa para gerenciamento das Tags
do usuário autenticado, consumindo exclusivamente a API real criada na
TASK-4.1.

A implementação deve reutilizar o Design System consolidado e os padrões
já utilizados em:

- Contas de Ativo;
- Categorias;
- Despesas;
- Receitas;
- Transferências;
- Histórico.

NÃO implementar ainda associação de Tags às transações.
