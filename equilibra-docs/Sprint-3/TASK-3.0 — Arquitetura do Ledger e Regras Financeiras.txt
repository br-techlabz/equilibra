# 4. PRINCÍPIO CENTRAL

O ledger de transações deverá ser a fonte de verdade para movimentações
financeiras.

NÃO queremos como arquitetura principal:

AssetAccount.currentBalance mutável
e atualizado manualmente a cada operação.

---

# 5. SALDO

Conceitualmente:

currentBalance(account) =

initialBalance
+ receitas
- despesas
+ transferências recebidas
- transferências enviadas

Analise essa fórmula e confirme ou proponha melhoria.

---

# 6. SOURCE OF TRUTH

A fonte de verdade deve ser:

initialBalance
+
ledger de transações.

O saldo corrente deverá ser derivado.

---

# 7. NÃO DUPLICAR SALDO

Evitar persistir:

currentBalance

em AssetAccount nesta fase.

mas saldo não foi atualizado;

ou:

mas transação falhou.

# 12. TRANSFERÊNCIA

Transferência é especial.

Ela possui:

sourceAccount
destinationAccount

e:

sourceAccount != destinationAccount.

---

# 13. TRANSFERÊNCIA NÃO É RECEITA

Transferência recebida NÃO deve contar como Receita.

---

# 14. TRANSFERÊNCIA NÃO É DESPESA

Transferência enviada NÃO deve contar como Despesa.

---

# 15. DASHBOARD

Portanto:

Entradas =
soma de INCOME

Saídas =
soma de EXPENSE

Transferências não entram nesses dois KPIs.

---

# 16. PATRIMÔNIO

Transferência entre contas do mesmo usuário:

NÃO altera patrimônio líquido total.

Exemplo:

Banco:
1000 → 800

Carteira:
100 → 300

Patrimônio:

1100 antes
1100 depois.

Essa propriedade deverá virar teste obrigatório futuramente.
