# TASK-3.6 — Casos de Uso e API REST de Transferências

Esta TASK deverá implementar a API completa de transferências entre
AssetAccounts do mesmo usuário.

O usuário autenticado deverá conseguir:

- criar uma transferência;
- listar transferências;
- consultar uma transferência;
- editar uma transferência;
- cancelar uma transferência.

Uma transferência representa UMA operação financeira que:

- debita uma conta de origem;
- credita uma conta de destino;
- deve ocorrer atomicamente;
- não é Receita;
- não é Despesa;
- não altera o patrimônio líquido total do usuário.

NÃO implementar nesta TASK:

- frontend de Transferências;
- Dashboard financeiro real;
- Tags;
- Attachments;
- upload;
- relatórios;
- saldo persistido;
- DELETE físico;
- API genérica de Transactions;
- full double-entry bookkeeping;
- abstrações genéricas prematuras.

# 3. PRINCÍPIO FUNDAMENTAL

Transferência:

Conta A
→ Conta B

Valor:

X

A -= X
B += X

Δ patrimônio = -X + X = 0
