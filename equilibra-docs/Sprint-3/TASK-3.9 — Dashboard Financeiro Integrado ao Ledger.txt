# TASK-3.9 — Dashboard Financeiro Integrado ao Ledger

Objetivo:

Transformar o Dashboard existente em um Dashboard financeiro REAL,
alimentado pelo ledger.

Implementar corretamente:

1. Entradas do período;
2. Saídas do período;
3. Saldo do período;
4. Patrimônio líquido atual;
5. Evolução dos saldos no período;
6. Transações recentes;
7. Resumo das contas com saldo corrente.

O Dashboard NÃO deve calcular regras financeiras no Angular.

O backend é a autoridade para:

- agregações;
- classificação financeira;
- saldos;
- patrimônio;
- séries históricas.

---

# 1. PRINCÍPIO FUNDAMENTAL

Separar claramente:

FLUXO
versus
POSIÇÃO.

Fluxo depende de período:

- Entradas;
- Saídas;
- Saldo do período;
- gráfico/evolução conforme definição aprovada.

Posição atual:

- Patrimônio líquido;
- saldo corrente das contas.

Patrimônio atual NÃO deve mudar simplesmente porque o usuário selecionou
outro período no Dashboard.
