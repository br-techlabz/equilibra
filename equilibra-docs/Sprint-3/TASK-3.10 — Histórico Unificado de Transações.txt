# TASK-3.10 — Histórico Unificado de Transações

Objetivo:

Criar uma visão unificada, paginada e filtrável de TODAS as transações
financeiras do usuário:

- Despesas;
- Receitas;
- Transferências.

Essa visão será a fonte de consulta cronológica geral do Equilibra.

IMPORTANTE:

Uma transferência deve aparecer como UMA única transação.

NUNCA:

Transferência = saída + entrada na listagem.

A API e a interface devem preservar a semântica real do ledger.
