# TASK-3.5 — Interface de Receitas

O objetivo é implementar a interface completa de Receitas/Rendas utilizando:

- a API REAL criada na TASK-3.4;
- o Design System existente;
- os padrões consolidados pela interface de Despesas;
- os componentes compartilhados já existentes.

O usuário deverá conseguir:

- visualizar receitas;
- registrar receita;
- editar receita;
- cancelar receita;
- visualizar receitas canceladas;
- navegar pela paginação;
- utilizar filtros suportados pela API;
- utilizar a funcionalidade adequadamente em desktop e mobile.

NÃO implementar nesta TASK:

- Transferências;
- Tags;
- Attachments;
- upload;
- Dashboard financeiro real;
- relatórios;
- saldo corrente persistido;
- DELETE físico;
- reativação sem suporte da API;
- GenericTransactionForm;
- GenericTransactionCrud;
- framework genérico de transações.
