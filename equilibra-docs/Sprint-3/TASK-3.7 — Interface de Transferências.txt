# TASK-3.7 — Interface de Transferências

Objetivo:

Implementar a interface completa de Transferências entre Contas de Ativo,
utilizando exclusivamente a API REAL criada na TASK-3.6.

O usuário deverá conseguir:

- visualizar transferências;
- criar transferência;
- editar transferência;
- cancelar transferência;
- visualizar transferências canceladas;
- navegar pela paginação;
- utilizar filtros suportados pela API;
- utilizar a funcionalidade em desktop e mobile.

Uma transferência representa UMA operação financeira:

Conta de origem
    ↓
   valor
    ↓
Conta de destino

Ela NÃO é:

- Expense;
- Income;
- duas transações independentes.

NÃO implementar nesta TASK:

- Dashboard financeiro real;
- saldo corrente;
- patrimônio derivado;
- relatórios;
- Tags;
- Attachments;
- upload;
- DELETE;
- reativação sem suporte da API;
- GenericTransactionForm;
- GenericTransactionCrud;
- nova arquitetura de ledger.
