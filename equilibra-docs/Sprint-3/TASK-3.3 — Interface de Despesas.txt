- TASK-3.0 — Arquitetura do Ledger e Regras Financeiras
- TASK-3.1 — Domínio e Persistência de Transações Financeiras

Agora implemente:

# TASK-3.3 — Interface de Despesas

Esta TASK deverá criar a primeira interface de movimentação financeira
real do Equilibra.

O usuário deverá conseguir:

- visualizar despesas;
- criar despesa;
- editar despesa;
- cancelar despesa;
- consultar despesas canceladas;
- navegar pela listagem paginada, se a API possuir paginação;
- visualizar corretamente estados de loading, empty, error e retry.

A interface deverá utilizar exclusivamente a API REAL implementada na
TASK-3.2.

NÃO implementar nesta TASK:

- Receitas;
- Transferências;
- Tags;
- Attachments;
- upload;
- Dashboard financeiro real;
- relatórios;
- saldo corrente;
- exclusão física;
- reativação de despesas, salvo se explicitamente suportada pelo ADR/API;
- CRUD genérico;
- abstração prematura de formulários financeiros.
