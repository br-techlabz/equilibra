# TASK-6.4 — DASHBOARD DE ACOMPANHAMENTO DE ORÇAMENTOS

PROJETO: EQUILIBRA
SPRINT: 6 — PLANEJAMENTO FINANCEIRO
STACK: Angular 19 + Angular Material + ECharts
BACKEND: Spring Boot 4 + MySQL

CONTEXTO

Sprint 5 aprovada.
TASK-6.0 — Arquitetura concluída.
TASK-6.1 — Backend de orçamentos concluído.
TASK-6.2 — Interface de gestão de orçamentos concluída.
TASK-6.3 — Backend de planejado versus realizado concluído.

OBJETIVO

Implementar a experiência visual de acompanhamento
mensal dos orçamentos por categoria, consumindo
exclusivamente os dados reais calculados no backend.

A interface deverá apresentar:

- resumo mensal;
- total planejado;
- total realizado;
- valor restante;
- percentual de consumo;
- comparação por categoria;
- gráficos e barras de progresso;
- navegação entre competências;
- tratamento de estados vazios e erros.

Não implementar regras financeiras no Angular.

O ADR da TASK-6.0 e os contratos reais da TASK-6.3
prevalecem sobre exemplos deste prompt.
